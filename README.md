NOIR FRAME is a photographer portfolio website built with HTML5, CSS & Tailwind CSS, and custom animations. Its cinematic identity combines dark backgrounds, amber accents, elegant typography, and expressive photography.

The homepage introduces the photographer with a hero statement and a featured golden-hour image. The philosophy section presents photography as a way of seeing, while the gallery features four collections: Human Stories, Wild Silence, The Vows, and Far From Here.

A visual statement adds atmosphere, followed by a profile of photographer Alex with experience and project metrics. The services section features Personal Portraits, Wedding Stories, Travel & Editorial, and Commercial Projects. A contact section invites visitors to discuss new projects, while the footer provides navigation and social links.

Tailwind CSS powers the layout and styling, supported by custom keyframe animations, hover transitions, responsive utility classes, and reduced-motion support. The result is a polished portfolio focused on visual storytelling, creative perspective, and memorable photography.
